# IT-Kerek

## Локальный запуск

Нужен Windows PowerShell. Для доставки заявок задайте новый токен бота и ID личного чата или группы в окружении текущего процесса, затем запустите сервер из того же окна PowerShell. При вводе токена используйте защищённое приглашение, а не вставляйте его в команду:

```powershell
$secureToken = Read-Host "Telegram bot token" -AsSecureString
$tokenPointer = [Runtime.InteropServices.Marshal]::SecureStringToBSTR($secureToken)
try {
  $env:ITKEREK_TELEGRAM_BOT_TOKEN = [Runtime.InteropServices.Marshal]::PtrToStringBSTR($tokenPointer)
} finally {
  [Runtime.InteropServices.Marshal]::ZeroFreeBSTR($tokenPointer)
}
$env:ITKEREK_TELEGRAM_CHAT_ID = Read-Host "Telegram chat ID"
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\server.ps1
```

Сайт доступен по адресу `http://127.0.0.1:8765/`, панель управления — `http://127.0.0.1:8765/admin/`.
При первом запуске сервер попросит задать пароль в защищённом приглашении PowerShell. В текущей локальной копии первоначальный пароль установлен как `admin123`; смените его в разделе «Безопасность» перед использованием панели.

## Языки и логотип

Публичные страницы доступны на русском, кыргызском (кириллица) и английском языках. Переключатель находится в шапке; выбранный язык сохраняется в браузере. Новый знак IT-KEREK хранится в `assets/it-kerek-logo.png` и используется на сайте и в панели управления.

Перед настройкой отзовите ранее опубликованный токен через BotFather и создайте новый. Добавьте бота в нужный чат или группу и убедитесь, что у него есть право отправлять сообщения. Форма передаёт имя, телефон, email и комментарий в указанный чат; эти заявки не сохраняются в файлах сайта. Токен не помещайте в исходный код, Git или сообщения. Если переменные окружения не заданы, форма честно сообщит, что отправка пока не настроена.

В `data/admin-auth.json` хранится только солёный PBKDF2-хеш пароля. Файл аналитики и данные входа исключены из Git. Содержимое сайта сохраняется в `data/site-data.json`.

## Аналитика и ограничения

Сервер слушает только loopback-интерфейс `127.0.0.1`, поэтому панель и аналитика доступны только на этом компьютере. Посетительские просмотры и клики пишутся в `data/analytics.jsonl`; IP-адреса, пользовательские идентификаторы и поля форм не сохраняются. Когда журнал достигает установленного лимита, остаются последние события.

Чтобы собирать аналитику с публичного сайта и публиковать правки для всех посетителей, приложение нужно развернуть на сервере с HTTPS, постоянным защищённым хранилищем и серверной авторизацией. Локальный сервер из этого проекта не следует открывать в интернет.
